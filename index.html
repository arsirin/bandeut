개인정보처리방침

시행일 2026년 10월 22일

요약먼저 알아두실 것

  • 반듯 체형측정(이하 ‘앱’)은 체형관리샵·물리치료 센터 등 사업자가 고객 기록을 관리하는 앱이에요.
  • 고객 기록과 사진은 기본으로 사용하는 기기 안에만 저장돼요. 개발자는 이 기록을 받지 않아요.
  • ‘기기 간 동기화’를 켜면 기록이 기기에서 잠긴(암호화된) 상태로 서버에 올라가요. 잠금을 푸는 열쇠는 서버에 보내지 않아서 개발자도 내용을 볼 수 없어요.
  • 사진 속 자세를 찾는 AI는 기기 안에서 돌아가요. 사진을 외부로 보내 분석하지 않아요.
  • 광고, 사용자 추적, 정보 판매는 하지 않아요.

1누가 어떤 정보를 다루나요

앱에는 두 종류의 정보가 있어요.

구분내용책임
고객 정보앱을 쓰는 샵(사업자)이 고객에게 받아 앱에 넣는 정보각 샵이 개인정보처리자로서 관리해요. 고객의 열람·정정·삭제 요청은 해당 샵에 하시면 돼요.
앱 사용자 정보동기화를 쓰는 사업자의 계정 정보(이메일 등)앱 개발자가 이 방침에 따라 처리해요.

2앱 안에 저장되는 정보

샵이 앱을 쓰면서 아래 정보가 기기 안에 저장될 수 있어요.

항목예
고객 기본 정보이름(손글씨 이미지 포함), 연락처, 생년월일, 성별, 키, 알게 된 경로
건강 관련 정보건강 체크 답변, 통증 정도, 불편한 부위 표시, 관리 요청사항, 방문 기록, 원장 메모·필기
동의 기록동의서 이미지, 서명, 동의 항목(필수·선택), 작성 일시
체형 사진·측정값정면·옆면 사진(얼굴은 자동으로 가림), 기울기·각도 등 측정값, 결과지
샵 설정샵 이름·로고, 관리자 PIN(복원할 수 없는 형태로 저장), 동의서 양식

건강 관련 정보와 사진은 민감한 정보예요. 샵은 앱의 동의서 기능 등으로 고객에게 수집·이용 동의를 받은 뒤 사용해야 해요.

3기기 간 동기화 (선택)

설정에서 동기화를 켜면 같은 계정의 태블릿·휴대폰끼리 기록을 맞추기 위해 아래 정보가 서버(Google Firebase)에 저장돼요.

항목목적보관
이메일, 비밀번호(Firebase가 암호화해 보관)로그인계정을 삭제할 때까지
암호화된 기록·사진, 기록 종류·번호·수정 시각기기 간 동기화
연결된 기기 이름(예: 태블릿 · SM-X…), 마지막 접속 시각연결된 기기 표시
  • 기록과 사진은 기기에서 AES-256 방식으로 잠근 뒤 올라가요. 잠금을 푸는 열쇠는 사용자가 보관하는 ‘동기화 코드’로만 열 수 있고, 이 코드는 서버로 보내지 않아요.
  • 원본 사진은 찍은 기기에만 두고 서버에 올리지 않아요.
  • 서버는 Google LLC의 Firebase(Authentication, Cloud Firestore)를 써요. 접속 과정에서 IP 주소 등 기술 정보가 Google에 전달될 수 있어요.

4권한과 외부 기능

권한·기능쓰는 곳
카메라체형 사진 촬영. 찍은 사진은 기기 안에만 저장돼요.
사진·파일 고르기갤러리 사진 불러오기, 샵 로고 넣기, 백업 파일 복원 (사용자가 고른 파일만)
인터넷동기화(켠 경우), 손글씨 인식 모델 내려받기
손글씨 이름 읽기안드로이드에서 Google ML Kit를 써요. 인식은 기기 안에서 하고, 처음 한 번 인식 모델을 Google에서 내려받아요. ML Kit는 기능 개선을 위해 기기·앱 성능 정보를 Google에 보낼 수 있어요(손글씨 내용은 보내지 않아요).
공유(결과지·PDF·백업·의견 보내기)사용자가 직접 고른 앱(카카오톡, 메일 등)으로만 보내요. 의견 보내기에는 앱 버전·기기 정보가 붙고 고객 정보는 들어가지 않아요.

5보관 기간과 삭제

  • 기기 안의 기록: 샵이 지우거나 앱을 삭제할 때까지 보관돼요. 고객 상세 화면의 ‘고객 삭제’로 그 고객의 동의서·방문 기록·사진이 함께 지워져요.
  • 서버의 기록과 계정: 앱의 ⚙ 설정 › 기기 간 동기화 › 계정 삭제를 누르면 서버의 모든 기록·사진·기기 정보와 계정이 바로 지워져요. 앱을 쓸 수 없는 경우의 방법은 계정 삭제 안내를 보세요.
  • 백업 파일: 사용자가 만든 백업 파일(.rbk)은 사용자가 보관한 곳(구글 드라이브 등)에 있어요. 비밀번호를 걸 수 있고, 지우는 것도 사용자가 해요.

6제3자 제공·처리 위탁

개인정보를 제3자에게 팔거나 제공하지 않아요. 동기화를 켠 경우에만 서버 운영을 Google LLC(Firebase)에 맡기며, 이때 올라가는 기록은 위 3번처럼 암호화되어 있어요. 서버는 국외(Google 데이터센터)에 있을 수 있어요.

7안전하게 지키는 방법

  • 관리자 화면과 설정은 관리자 PIN으로 잠겨요. 쓰지 않으면 자동으로 닫히게 할 수 있어요.
  • 동기화 기록·사진은 기기에서 암호화해 보내고, 서버는 계정 주인만 읽고 쓸 수 있게 막아 두었어요.
  • 체형 사진은 화면과 결과지에서 얼굴을 자동으로 가려요.

8아동의 정보

앱은 사업자가 쓰는 앱이에요. 만 14세 미만 고객의 정보를 넣을 때는 샵이 법정대리인의 동의를 받아야 해요.
